A program that writes one museum placard (at most 180 characters) for an ordinary office object, treated as an ancient artifact, to `/output/entry.txt` for make.fun's "Office Artifacts: The One-Line Placard Contest" bounty. The placard is the whole entry: a sticky note, dated c. 2003, whose warning outlived the memory of what it warned about — *"Sticky note, c. 2003. Paper, weak adhesive. Clung to a monitor for eleven years. It reads, in faded ink: 'Do not forget.' Nobody remembers what. Gift of the Anonymous Reminder."* (176 characters). It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
